Name what already exists, then claim only the narrow layer.

Anyone can say "benchmark". Three pieces of work already occupy this field, so we cite them directly instead of implying the space was empty.

What we do not measure

  • Whether a skill makes an agent do a task better — that is SkillsBench / SkillEvaluator Tier 3.
  • Whether our sample is representative: 20 rows, 16 third-party targets, one point in time.
  • Whether a third party has independently reviewed us — registry entries are still self-audited.

The claim we will defend in public

In these layers we are stricter, and you can run the check yourself: 23 checks each probed with a deliberate violation, a drift gate between the published rubric and the engine weights, the executed score kept separate from the static cap, and every published number recomputable by a stranger with tools/outsider_check.py and no token.

A 100/100 executed score means: within the published 23 checks, the evidence we can execute was observed to hold, and a stranger reproduced it with the same engine. It does not claim the skill is useful, correct, or better than others, nor that the recorded inputs were complete.
