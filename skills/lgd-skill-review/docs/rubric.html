rubric

Six dimensions, 100 points, no black box.

Weights are public because a score nobody can recompute is an opinion with a number stapled to it. Static mode caps at 96; the last 4 points require the target's own tests to actually run.

DimensionWeightWhat it can prove
Consistency25Documented flags and subcommands exist in the source
Structure20Entry file, version, name, description are machine-findable
Reproducibility20A golden set exists and a runner actually executes it
Hygiene15No absolute paths, secrets or leaked contact details
Discoverability15Triggers, ecosystem links, AI-INDEX / llms.txt
Licensing5A real license file plus a declared field

What the score cannot tell you

  • Whether the skill is useful, correct, or popular
  • Whether the prose is any good
  • Whether the maintainer will respond to issues
  • Anything about packages it never saw

Two known measurement biases were found and fixed by testing the ruler against real repositories: index detection used to be case-sensitive, and position-argument CLIs were scored zero. Both are documented in the repository history.

Measures verifiability, not usefulness or popularity. Low score means evidence is missing, not that the skill is bad. Snapshot at a point in time; the sample is not random. Data: leaderboard.json · Machine entry: llms.txt · Request a review: open an issue
