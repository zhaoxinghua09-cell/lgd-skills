How to get on this list

  • Submit a public repository: review request（机器人取包、静态分析、回帖给分与整改顺序）
  • No payment, no negotiation, no editorial discretion. The runner decides.
  • Rejected? The reply lists what is missing and in what order to fix it. Resubmit after fixing.

机器可读版：registry.json（含每档阈值与全部条目）。

What a tier is not

It is not a quality endorsement, not a security audit, not a warranty. It says one thing: how much of this package's claims a stranger can verify in ten minutes. A verified package can still be useless; a blocked package can still be excellent — it just cannot be checked.

Measures verifiability, not usefulness or popularity. Low score means evidence is missing, not that the skill is bad. Snapshot at a point in time; the sample is not random. Data: leaderboard.json · Machine entry: llms.txt · Request a review: open an issue
